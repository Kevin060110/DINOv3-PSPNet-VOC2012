# 完全零基础也能看懂的项目说明

## 先说结论

你完成了一个让电脑“看懂照片”的人工智能项目。

人看到照片，很容易知道哪里是人、猫、汽车或背景。电脑原本不懂。本项目让电脑查看照片里的
每一个小点，并判断它属于什么东西。这项工作叫“语义分割”。可以把它想成涂色：电脑把人物
区域涂一种颜色，把汽车涂另一种颜色，把背景再涂一种颜色。

你的最佳方案取得了 **81.90% mIoU** 和 **96.05% 像素准确率**，成功完成了题目要求。

## 一、它有什么用？

普通图片分类只能说“照片里有一只猫”。语义分割还要指出猫具体占据照片中的哪些位置。
类似技术可以帮助自动驾驶汽车分辨道路、行人和车辆，也能用于医学影像、卫星照片、手机抠图
和机器人视觉。

## 二、电脑如何完成任务？

整个模型像两位合作的工人。

### 第一位：DINOv3

DINOv3 像见过大量照片的观察员。它能发现毛发、轮子、人物轮廓、天空和地面等视觉线索。

项目使用 **DINOv3 ViT-S/16**。这是题目要求中最小的 DINOv3 模型，约有2,160万个可以调整
的数字，可以把这些数字理解成它积累的经验。名字中的 `/16` 表示它把照片分成许多16×16的
小方块进行观察。

### 第二位：PSPNet

PSPNet 像负责综合判断的工作人员。它同时参考很小的局部、较大的周围和整张照片。例如，只看
一个灰色小块很难知道它是什么；结合全图，才可能发现它是汽车的一部分。

```text
输入照片
  ↓
DINOv3 找出视觉线索
  ↓
PSPNet 综合局部与整体
  ↓
判断照片中每个位置的类别
  ↓
得到人物、动物、车辆和背景等区域
```

## 三、电脑用什么教材学习？

电脑使用 **PASCAL VOC 2012** 数据集。它像一本带标准答案的练习册，包含真实照片以及人工
标记好的正确区域。

- 1,464张照片用于训练；
- 1,449张照片用于验证；
- 需要判断21类：1类背景和20类物体，包括人、猫、狗、汽车、火车、椅子等。

训练和验证照片分开，就像学生用练习题学习，再用没见过的题目考试。

## 四、“训练”是什么意思？

训练类似学生反复做题和订正：

1. 给电脑一张照片；
2. 电脑猜测每个位置是什么；
3. 将猜测与正确答案比较；
4. 计算错误程度；
5. 根据错误稍微调整模型；
6. 继续看下一张照片。

把全部训练照片看一遍叫一个 **epoch（轮）**，本实验训练了30轮。程序中的 `loss` 表示错误
程度，一般越小越好。

## 五、你比较了哪两种方法？

### 方法一：冻结 DINOv3

“冻结”不是放进冰箱，而是不改变 DINOv3 原来积累的经验，只让 PSPNet 学习。

```text
DINOv3：保留已有经验
PSPNet：学习本次分割任务
```

### 方法二：微调 DINOv3

“微调”表示 DINOv3 和 PSPNet 都继续改变。它看似更灵活，但训练照片不多，模型可能把练习题
背得很熟，却不善于回答没见过的新题。这种现象叫 **过拟合**。

## 六、成绩怎么理解？

### 像素准确率

数字照片由许多小点组成，每个点叫像素。像素准确率表示所有小点中有多少判断正确。不过照片
往往有大片背景，所以仅看这个数字不够。

### IoU 和 mIoU

IoU 衡量电脑涂出的物体区域和正确区域重合得多好。可以想象两张剪纸：一张是正确的猫，另一张
是电脑找到的猫。两张重合越多、错误伸出的部分越少，IoU 越高。

21类分别有自己的 IoU，把它们平均起来就是 **mIoU**。它是本项目最重要的综合成绩，越高越好。

## 七、你的实验成果

| 方法 | Loss（越低越好） | 像素准确率 | mIoU（最重要） |
|---|---:|---:|---:|
| 冻结 DINOv3 + PSPNet | **0.1438** | **96.05%** | **81.90%** |
| 微调 DINOv3 + PSPNet | 0.5007 | 92.38% | 72.93% |

结论是：**保留 DINOv3 的已有经验，只训练 PSPNet，效果最好。** 冻结方案的 mIoU 高出
8.98个百分点。冻结方案第29轮最好；微调方案第24轮最好。程序自动保存了最好的一轮。

冻结方案最擅长的前景类别包括：猫93.85%、公共汽车93.47%、狗92.80%、鸟90.80%和人
90.69%。较困难的类别包括椅子51.44%、自行车55.98%和盆栽65.82%。这些物体常有细杆、空隙
和复杂边缘，而模型隔着16×16方格观察，容易漏掉细节。

## 八、为什么微调反而变差？

微调模型最后在训练照片上达到96.22% mIoU，但在验证照片上只有71.89%。这说明它很会做见过
的题，却不够擅长新题，属于明显过拟合。

可能原因包括：

1. 训练照片只有1,464张，而模型可以改变的数字很多；
2. 修改整个 DINOv3 可能破坏原本有用的通用视觉经验；
3. 微调使用320×320图片，冻结实验使用384×384图片，看到的细节更少；
4. 微调每次只看1张图片，学习过程更容易波动；
5. 训练图片的变化方式较简单，容易被记住。

所以，准确结论不是“微调永远不好”，而是：**在本次数据量和训练设置下，冻结方案更好、更稳定。**
由于两组图片尺寸和每次处理的图片数不同，这不是完全严格的单变量比较。后续可以统一条件再实验。

## 九、主要代码在做什么？

你不需要会编程。下面按“一张照片进入程序以后”的顺序解释主要代码。

### 1. `data.py`：准备照片和答案

```python
image = TF.resize(image, [self.size, self.size])
mask = TF.resize(mask, [self.size, self.size], InterpolationMode.NEAREST)
```

`image` 是照片，`mask` 是人工标好的答案。两者必须一起改变大小。答案使用“最近邻”缩放，避免
代表类别的整数被混成小数。训练时，代码还会把照片和答案同时左右翻转，增加变化、减少死记。
`DataLoader` 像发练习册的人，每次取出几张照片，并在每轮开始时打乱顺序。

### 2. `model.py`：DINOv3 观察照片

```python
features = self.backbone.forward_features(images)
tokens = features["x_norm_patchtokens"]
```

`backbone` 就是 DINOv3。`patch tokens` 是它对每个16×16小方块写下的观察笔记，每个方块用
384个数字描述。它使用已经验证过的预训练权重，因此不是随机猜测。

```python
feature_map = tokens.transpose(1, 2).reshape(
    batch, 384, height // 16, width // 16
)
```

DINOv3 的笔记原本排成一长排，这段代码把它们摆回照片中的二维位置。例如384×384照片，每边
有 `384÷16=24` 个方块，最终得到24×24的“特征地图”。

### 3. PSPNet 的 PPM：同时看细节和全局

```python
PyramidPoolingModule(in_channels, bins=(1, 2, 3, 6))
```

`1、2、3、6` 是四种观察尺度，相当于把照片概括成1×1、2×2、3×3和6×6四份摘要。
程序用 `torch.cat` 把这些摘要和原始特征拼在一起，让模型判断局部时也能参考整张照片。

### 4. 分割头：每个位置做21选1

```python
nn.Conv2d(256, num_classes, 1)
F.interpolate(logits, input_size, mode="bilinear")
```

`num_classes=21`，表示每个位置得到21个类别分数，最高分就是预测类别。由于 DINOv3 的特征图
比原图小，`interpolate` 再把结果放大回原图尺寸。

### 5. 如何控制冻结和微调？

```python
parameter.requires_grad = trainable
```

它可以理解成“是否允许修改”。为 `False` 时 DINOv3 被冻结；为 `True` 时可以微调。冻结时的
`torch.no_grad()` 表示只观察、不保存修改 DINOv3 所需的记录，因此更省显存。

### 6. `engine.py`：上课、批改和订正

```python
logits = model(images)
loss = criterion(logits, masks)
loss.backward()
optimizer.step()
```

四行依次表示：模型回答、和标准答案比较、从错误反查原因、稍微调整参数。

```python
nn.CrossEntropyLoss(ignore_index=255)
```

这是21选1问题的批改方法。VOC 中255代表模糊边界或不评分的位置，代码会忽略它们。

### 7. `metrics.py`：计算考试成绩

程序建立21×21的表，记录“正确类别是什么”和“电脑猜成什么”，再计算：

```python
iou = intersection / union
miou = iou.mean()
```

`intersection` 是电脑区域和正确区域重合的部分，`union` 是二者合起来的区域。每类得到一个
IoU，21类平均得到 mIoU。程序汇总全部1,449张验证照片后再计算。

### 8. `train.py`：训练总指挥

它负责建立模型、读取数据、训练一轮、验证一轮、记录结果，再进入下一轮：

```python
if val_result["miou"] > best_miou:
    save_checkpoint(...)
```

只有当前 mIoU 超过历史最好成绩，才保存 `best.pth`。所以冻结实验保存第29轮，微调实验保存
第24轮，而不是盲目使用最后一轮。

### 9. `evaluate.py`：正式考试

它读取 `best.pth`，在全部验证照片上只考试、不学习，并把 loss、像素准确率、mIoU 和各类别
IoU 写进 `evaluation.json`。

### 10. `analyze_results.py`：把数字画成图

它读取两组 `history.json` 中每一轮的成绩，生成 `training_curves.png`，让我们直观看到冻结方案
较稳定，而微调方案的训练和验证成绩逐渐分离，即出现过拟合。

## 十、项目文件是做什么的？

把项目想成一个厨房：

### 说明与成果

- `reports/零基础项目说明.md`：你正在阅读的通俗说明。
- `reports/experiment_report.md`：可以提交给老师的正式技术报告。
- `reports/training_curves.png`：展示30轮训练中成绩变化的图片。
- `README.md`：安装和运行说明书。

### 工作程序

- `train.py`：训练程序，像上课和批改练习的老师。
- `evaluate.py`：考试程序，负责计算最终成绩。
- `analyze_results.py`：读取成绩并绘制曲线。
- `dinov3_pspnet/model.py`：规定 DINOv3 和 PSPNet 如何合作，是模型核心。
- `dinov3_pspnet/data.py`：读取照片和标准答案。
- `dinov3_pspnet/engine.py`：控制一轮一轮的训练与验证。
- `dinov3_pspnet/metrics.py`：计算准确率、IoU 和 mIoU。
- `dinov3_pspnet/utils.py`：保存、读取模型等辅助工作。

### 实验结果

- `outputs/frozen/`：冻结实验结果。
- `outputs/finetuned/`：微调实验结果。
- `best.pth`：表现最好的模型，像“最佳学生档案”。
- `last.pth`：最后一轮模型，不一定最好。
- `evaluation.json`：最终考试成绩。
- `history.json`：每一轮的完整成绩。

### 教材和工具

- `external/dinov3/`：DINOv3 官方代码。
- `data/VOCdevkit/VOC2012/`：照片与人工标准答案。
- `.venv/`：装有项目专用工具的工具箱。
- `requirements.txt`：项目所需工具的清单。

## 十一、训练曲线怎么看？

打开 `reports/training_curves.png`：

- 左图是 mIoU，越高越好；
- 右图是 loss，越低越好；
- 实线是验证照片，虚线是训练照片；
- 蓝线是冻结方案，红线是微调方案。

如果训练成绩越来越好，但验证成绩没有同步提高，表示模型可能在死记练习题。图中微调方案的
训练线和验证线距离很大，这正是过拟合的证据。
